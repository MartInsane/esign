# How to install IPA files without PC (E-Sign method)


Do you want to install **any IPA file** on your iOS device **without PC**? You are at the right place!
**E-Sign** is a tool app which lets you sign and download any IPA file.


## __Disclaimer 1:__ Apps installed via sideload certificates remain functional as long as the signing certificate is valid. Certificates are typically valid for up to 1 year, but may be revoked earlier by Apple, which can cause the apps to stop opening. In this case, download another version of E-Sign or a new certificate.
